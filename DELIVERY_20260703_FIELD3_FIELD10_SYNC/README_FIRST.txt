HOW TO VERIFY THE REPAIR

1. Open Settings.
2. Select the required symbols and run the existing Quick Run + Open Lunch action.
3. At the top of Lunch, confirm the current canonical run symbol is selected (for the supplied case, NZDUSD instead of stale EURUSD).
4. Open Field 3:
   - Choose “Settings completed symbols” to load a saved run, or
   - Choose “Plan B — Top 10 Currency Pairs”, select one pair, and press Connect / Load Field 3.
5. Open Field 10.
6. The first table is now “Field 3 Higher-Standard Multi-Symbol Bias — All Completed Settings Symbols”.
7. Check each symbol’s Higher-Standard Bias, Less-Risky Bias, evidence source, data quality, and rank.

Important: the Plan B local calculation is exact-symbol, completed-H1, display-only evidence. It does not overwrite the protected production decision.
