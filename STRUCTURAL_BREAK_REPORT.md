# Structural Break Report

## Classification: SHADOW_ONLY

The candidate searches causal completed-H1 splits for changes in return mean, realized volatility and trend slope, and records provider-dependent spread/tick-volume differences when available. Session and technical coefficient proxies are included; news-response, EV-residual and calibration-residual components stay NULL until aligned ledgers exist. Lightweight online-change probability and run-length evidence are also recorded.

A severe recent break may set `BLOCK_NEW_ENTRY`. It never changes the locked morning rank, bias, forecast or original probability. No production improvement claim is made.
